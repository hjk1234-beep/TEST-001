→ 신세계백화점 도착. iM카드 A로 3만원 더 결제하면 이번 달 실적 30만원을 채워 5% 할인이 적용됩니다.
  1. 앱이 백그라운드 지오펜싱으로 가맹점 반경 진입 감지
  2. 앱 → Claude API 호출 (iM카드 MCP를 도구로 연결)
  3. LLM이 MCP 도구로 카드·혜택·실적 조인
  4. 결과를 푸시 알림으로 발송 → 탭 시 앱 화면에 근거 표시

→ iM카드 A가 유리합니다. 실적 27/30만원으로 3만원만 더 쓰면 5% 구간에 진입합니다.
  1. 사용자가 iM카드 MCP를 커넥터로 직접 추가

앱 측 신규 개발지오펜싱 · 푸시없음
B안에서 구축하는 MCP 도구 4종이 E안에 그대로 재사용되며, E안은 앱 측 신규 개발 없이 커넥터 연결만으로 성립함. 즉 시범과제 결과물이 폐기되지 않고 접점 확대 시 개발 범위를 줄이는 구조.
전제 및 통제
  • 뱅킹 앱 미사용 — 시범과제 전용 데모 앱을 별도 제작, 앱스토어 심사 없이 시연 단말에 직접 설치(사이드로드)
  • 위치정보는 은행 API가 아닌 단말에서 직접 취득, 가맹점 좌표 매칭만 서버에서 수행
  • 혜택 계산은 100% 규칙 기반, LLM은 해석·설명만 담당 — 결제 실행은 사용자 확인 후에만 개시
